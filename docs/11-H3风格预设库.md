# 11 · MiniMax H3 风格预设库（短剧生产版）

> 目的：一套可直接落进分镜/渲染链的风格预设 + 词库 + 模板。古风、仙侠、都市、悬疑、科幻、动画、特殊介质全覆盖。
> 用法：① 项目选一个主风格（`style_id`）→ ② 渲染时把该风格的 `render` 原文拼在镜头画面描述**之前**（权重最高）→ ③ 光线/色调/质感作为该风格的固定附加段，不随镜头漂移。
> 配套 YAML：`config_defaults/presets_h3_styles.yaml`（可直接合并进 `presets.yaml` 的 `styles:`）。

---

## 0 · 先读：H3 的硬约束（写提示词前必须知道）

来源：MiniMax 官方 Base / Full-Reference 提示词指南、ComfyUI 官方 H3 文档、fal 实测 44 例。

| 项 | 值 | 对提示词的影响 |
|---|---|---|
| 时长 | **4-15 秒**（整数） | 6 秒装不下三幕。一个镜头只写**一个主事件** |
| 帧率 | 24 fps | 动作密度按 24fps 写，别写"慢动作 0.5x"这种要后期的东西 |
| 音频 | **原生 32kHz 立体声**同生 | 声音是提示词输入，不是后期 |
| 原生画布 | 短边 **768px**（16:9 = 1344×768），宽度取 **32 的倍数** | 竖屏 768×1344 |
| 帧数网格 | **17k+5**（ComfyUI `length`） | 5s≈124 帧；写时长时按整秒，节点自己吸附 |
| 提示词上限 | **7000 字符**（V2 API） | 够写整份分镜，但**不建议**写满 |
| negative 字段 | **没有** | 本栈 `build_h3()` 的 `negative` 参数被忽略（源码注释已确认）。**负面只能写成自然语言陈述句** |
| 相机命令 | 有固定词表，见 §6 | 一个镜头**只给一种主运镜**，叠加必然糊 |
| 参考图 | Ref2VA 最多 9 图 / 3 视频 / 3 音频 / 共 12 个 | 参考图张数 ≠ 质量，**一张干净的比五张打架的强** |

### 0.1 官方三字段结构（本栈渲染链路应产出这个形状）

```
integrated_multimodal_description: [Shot 1] 整体风格、开场构图、主体外观与位置、环境、光线、第一个动作……
                                   [Shot 2] At 00:03.500, …（后续镜头带严格递增时间码）
overall_soundscape: 环境底噪、物理音效、非语言人声（不重复台词、不重复配乐）
non_diegetic_music: 观众才能听到的配乐（乐器/速度/节奏/变化），不要就写 N/A
```

- **`[Shot 1]` 不带时间码**；后续镜头必须 `[Shot N] At MM:SS.mmm,`。
- 切镜必须带来**新主体 / 新空间 / 新状态 / 新视角 / 新时间**；只是距离或角度小变化 → 用运镜，别切。
- 台词绑定说话人：`(S1)`/`(S2)`，**身份与语气写在标签外，`<d>` 内只放语言标记 + 原文**：

  ```
  白衣女子压低声音（S1）说：<d>[Chinese] 你早就知道，对不对？</d>
  她说完，对面男人（S2）没有开口，只是把茶杯放回桌面。
  ```

- 画外音必须写 `画外音（off-screen voiceover）` 并紧接一句「画内角色嘴唇始终闭合」。
- 跨剪辑延续的一句台词：两处接缝都写 `<scenetrans>`；视频在一句话中途结束写 `<cutoff>`。
- 屏幕可见文字（招牌/字幕/UI）用**英文双引号原样照抄**，不翻译不改写：

  ```
  门头红色霓虹招牌写着 "OPEN"，全程不被遮挡。
  ```

### 0.2 负面约束的正确写法（H3 没有 negative 字段）

不要指望 `blurry, watermark, extra limbs` 生效——那套是给有 negative 分支的模型写的。

**做法：镜头内正向描述 + 一句自然语言排除句。**

```
（正向）中景，白衣女子站在廊下，右手扶栏杆，侧脸朝向庭院，眼神落在远处灯笼上。
（排除句）画面内不要出现文字、水印、字幕条；不要出现第三个人；她右手只有五根手指。
```

规则：
- 排除句放在**该镜头描述末尾**，不要单独一段。
- 一次最多写 2-3 条排除，且**只写这次最容易错的那几条**（人数、手指、文字、口型）。
- 别写"不要模糊/不要低质量"——模型无法把"质量"当作可排除的对象，反而稀释真指令。

## 1 · 风格预设的写法（五段式）

每个风格 = 五个固定段，拼起来就是镜头提示词的前半部分：

```
[风格总述]  →  [光线设定]  →  [色调与调色]  →  [材质与质感]  →  [镜头语言倾向]
```

之后才是镜头自身的**主体 + 动作 + 环境 + 运镜 + 声音**。

**关键原则：风格段必须逐字复用。** 同一集里每个镜头都用同一串字符，一致性靠"完全相同"，不靠"意思差不多"。

## 2 · 风格预设库

> 每条给出：`id` / 中文名 / 完整 render（可直接拼）/ 光线 / 色调 / 质感 / 运镜倾向 / 声音倾向 / 排除项 / 适用剧型。

### A · 东方古装（12）

#### A1 `guofeng` 古风国潮
- **render**：中国古风美学，宋式庭院与木构建筑，青灰瓦顶、白墙、竹影；人物着素色交领汉服，衣料为哑光棉麻与薄纱；电影感，自然光为主
- **光线**：晨间侧逆光穿过窗棂形成光柱；烛火做点缀光；不强打正面光
- **色调**：青绿与米白为主，低饱和，暗部偏青
- **质感**：棉麻哑光、木纹、宣纸、青苔石阶
- **运镜**：固定中景为主，缓慢横移看庭院；慎用快速推拉
- **声音**：风过竹叶、檐角铁马、远处木鱼、衣料摩擦
- **排除**：不要现代物件、不要塑料感衣料、不要浓艳饱和色
- **适用**：古风虐恋、宅斗、文人戏、文旅宣传

- **色调**：冷白与淡金，远景压青，近景提亮
- **质感**：丝绸高光、玉石半透、云雾颗粒、法术光丝
- **运镜**：缓慢升镜揭示云海；环绕半圈看人；起势瞬间只推一次
- **声音**：高空风声、衣袂猎猎、远处钟磬、法术低鸣

#### A3 `xianxia-dark` 仙侠暗黑 / 魔道 ⚠️

- **光线**：单一逆光或侧顶光，人物面部一半沉入黑暗；地面有熔岩或血色的低位反光
- **色调**：黑、暗红、锈金，极低明度
- **质感**：干裂岩石、锈铁、湿血、烟尘
- **运镜**：低机位仰拍，手持轻微晃动；爆发瞬间快速推近
- **声音**：闷雷、金属拖地、粗重呼吸、低频轰鸣
- **排除**：不要明亮天空、不要干净整洁的服装、不要笑脸
- **⚠️ 坑**：夜景+暗调是 H3 最易糊的场景。**必须写明具体光源**（"左侧燃烧的残垣提供主光，照亮她右半边脸"），否则整段发黑

#### A4 `wuxia` 武侠江湖
- **render**：中国武侠，青石板长街与木质酒楼，酒旗、灯笼、木柱上的刀痕；人物着粗布劲装、束发、窄袖，腰佩刀剑；尘土可见，颗粒感胶片

### B · 现代都市（12）

#### B1 `urban-realism` 都市写实
- **render**：现代都市写实风格，真实街景与室内，自然光，浅景深，35mm 胶片颗粒
- **光线**：窗光与室内灯混合，不额外打光
- **色调**：中性偏暖，克制
- **质感**：真实皮肤（毛孔可见）、棉质衣物、玻璃与水泥
- **运镜**：固定或极缓推近；对话用中景过肩
- **声音**：城市底噪、空调、远处车流
- **排除**：不要塑料感皮肤、不要过度磨皮、不要广告式打光
- **适用**：都市情感、职场、家庭

#### B2 `urban-night` 都市夜景霓虹
- **render**：现代都市夜景，霓虹倒影、湿滑街道、玻璃幕墙；人物在灯牌下形成剪影或侧光；青橙对比调色，电影感，虚化光斑
- **光线**：店铺灯牌做人物主光（写清颜色与方位，如"右侧粉色招牌照亮她左脸"）
- **色调**：青 + 橙 + 品红，暗部保留细节
- **质感**：湿沥青反光、金属、雾气
- **运镜**：跟拍行走、缓慢横移；不摇不晃

- **排除**：不要慢动作特效、不要飞舞的血液、不要超过两人同框
- **⚠️ 坑**：肢体接触动作必须只写一个动作链（"右直拳打向对手下颌，对手后仰"，不要写连招）
- **适用**：格斗、体育、逆袭

### D · 动画 / 风格化（9）

#### D1 `anime` 二次元番剧

- **光线**：动画式简化光照，明暗分界清晰，允许非物理的轮廓光
- **色调**：中高饱和，暖色为主
- **质感**：平涂色块、网点、线条
- **运镜**：快速推近、横向甩镜（可稍夸张）、固定特写
- **声音**：清脆脚步、衣料、风、动画式夸张音效
- **排除**：不要写实皮肤纹理、不要真实毛发、不要实拍光影
- **适用**：番剧、国漫、二次元短剧

#### D2 `anime-90s` 90 年代赛璐璐
- **render**：1990 年代日本动画，手绘赛璐璐质感，胶片颗粒与轻微色偏，线条略不均，阴影为硬边单层；色彩偏褪，带老录像带的柔化
- **光线**：简化动画光照，高位侧光
- **色调**：褪色暖调、略偏绿
- **质感**：胶片划痕、轻微抖动、色带
- **运镜**：传统动画的平移与推近，允许轻微画面抖动
- **声音**：老式音效、磁带底噪、合成器配乐
- **排除**：不要数字绘画的干净锐利、不要现代高饱和
- **适用**：复古番、怀旧、青春

#### D3 `cg-chinese` 3D 国漫
- **render**：中国 3D 动画电影质感，写实比例但风格化面部，布料与发丝有物理模拟感，服装细节丰富（刺绣、金属扣）；环境为高精度建模

- **运镜**：电影级运镜（推轨、环绕、升降）都可用
- **声音**：宏大弦乐、布料摩擦、脚步
- **排除**：不要低模感、不要塑料皮肤、不要二次元大眼
- **适用**：国漫、玄幻 3D、游戏宣传

#### D4 `cg-pixar` 欧美 3D 动画
- **render**：欧美 3D 动画电影风格，圆润造型与夸张表情，皮肤有柔和次表面散射，布料厚实；环境色彩明快，细节童趣
- **光线**：柔和大面积主光，几乎无硬阴影，允许鲜艳的环境反射
- **色调**：高明度高饱和
- **质感**：软塑料、绒布、木质
- **运镜**：大幅度推拉、环绕、快速切换
- **声音**：夸张拟音、轻快配乐
- **排除**：不要写实比例、不要暗调、不要血腥
- **适用**：亲子、喜剧、合家欢

#### D5 `stopmotion` 定格黏土
- **render**：定格动画，黏土/硅胶人偶，表面有指纹与轻微不完美，布料为真实微缩织物，场景为微缩模型；每帧有细微的手工抖动感

- **声音**：拟音感强的脚步声、吱嘎声

- **运镜**：漫画式的突然特写、速度线推进
- **声音**：拟声词外的实际音效（风声、脚步）

#### D9 `paper-cut` 剪纸皮影

- **声音**：锣鼓、二胡、幕后操作声

### E · 介质质感（10）

> 这一组不是"题材"，是"成像方式"。可以叠加在任何题材上（如 `wuxia` + `film-35mm`）。

#### E1 `film-35mm` 35mm 胶片
- **render**：35mm 胶片成像，可见细腻颗粒，高光有柔和晕开（halation），暗部有轻微色偏，宽容度高；浅景深，焦点过渡自然
- **光线**：自然，接受过曝高光
- **色调**：略偏暖，色彩有层次
- **质感**：颗粒、光晕、轻微划痕
- **运镜**：任何，但避免数字感极强的稳定器滑轨
- **声音**：不影响
- **排除**：不要锐利的数字边缘、不要 HDR 感

#### E2 `film-70s` 70 年代暖黄
- **render**：1970 年代电影质感，暖黄偏色，低对比，柔焦，轻微暗角；服装与布景有年代感；颗粒粗，色彩褪
- **光线**：柔和暖光，高光过曝
- **色调**：暖黄、橄榄绿、褐
- **质感**：粗颗粒、柔化、暗角
- **运镜**：缓慢变焦推近（年代感光学效果）
- **声音**：老式配乐、磁带底噪
- **排除**：不要锐利、不要冷调、不要现代清晰度

#### E3 `vhs` VHS 录像带
- **render**：VHS 录像带画质，扫描线、色度溢出、边缘振铃、画面轻微抖动与噪点；色彩偏移，白平衡不稳；4:3 感构图
- **光线**：平光，容易过曝
- **色调**：偏洋红/绿，低色度
- **质感**：扫描线、雪花噪点、磁带失真
- **运镜**：固定或手持
- **声音**：磁带底噪、音频失真
- **排除**：不要锐利细节、不要准确色彩

#### E4 `monochrome` 黑白
- **render**：黑白摄影，高对比，纯黑与纯白之间保留丰富中间调；靠光线与材质表现层次，不靠色彩
- **光线**：硬光创造强烈明暗分割
- **色调**：黑白灰
- **质感**：颗粒、皮肤质感、布料纹理
- **运镜**：固定或缓慢移动
- **声音**：不影响
- **排除**：不要任何彩色

#### E5 `silent-era` 默片
- **render**：1920 年代默片，黑白，硬光，画面轻微抖动与划痕，四角暗角明显；人物表演夸张，动作幅度大；字卡式的停顿感
- **光线**：强烈顶光与侧光，眼窝阴影重
- **色调**：黑白（可轻微褐色调）
- **质感**：胶片划痕、闪烁、抖动
- **运镜**：固定，偶尔横移
- **声音**：无对白，只有钢琴配乐与拟音
- **排除**：不要彩色、不要自然光、不要现代表演方式

#### E6 `documentary` 纪录片手持
- **render**：纪实风格，手持镜头，自然光，真实皮肤质感，不做风格化；构图不完美，焦点偶有呼吸
- **光线**：现有光，接受不均衡
- **色调**：中性，低饱和
- **质感**：真实、粗糙
- **运镜**：手持跟随，随机微调
- **声音**：现场同期声，环境嘈杂
- **排除**：不要补光痕迹、不要完美构图、不要磨皮

#### E7 `commercial` 广告大片
- **render**：高端商业广告，精密布光，产品与人物都有清晰轮廓光，背景为渐层或纯色；构图极简对称；每一帧都可作海报
- **光线**：三点光 + 背景光，可控且精确
- **色调**：干净、高对比、品牌色主导
- **质感**：镜面反射、精密材质、无瑕表面
- **运镜**：精确的推轨、环绕、升降，速度可控
- **声音**：定制配乐、干净拟音
- **排除**：不要杂乱、不要自然瑕疵、不要手持

#### E8 `macro` 微距产品
- **render**：微距摄影，极浅景深，产品表面纹理与微小划痕清晰可见；背景完全虚化为色块；水珠或雾气做点缀
- **光线**：侧逆光勾勒边缘，柔光箱正面补光
- **色调**：干净、高纯度
- **质感**：玻璃、金属拉丝、液体
- **运镜**：极缓推近或横向滑移
- **声音**：干净拟音、低频铺底
- **排除**：不要广角变形、不要杂乱背景

#### E9 `dreamcore` 梦核超现实
- **render**：梦核超现实，熟悉的场景被轻微扭曲：空的泳池、过曝的天空、重复的门、无人的游乐场；色彩过饱和但氛围空寂；像记忆而非现实
- **光线**：过度明亮的均匀光，无明确光源
- **色调**：过饱和的粉蓝与荧光绿
- **质感**：塑料、过曝、柔焦
- **运镜**：极缓推进，像凝视
- **声音**：混响的音乐盒、远处模糊人声、耳鸣般的嗡鸣
- **排除**：不要真实阴影、不要暗调、不要人物特写

#### E10 `cctv` 监控伪纪录
- **render**：安防监控视角，固定高机位俯拍，广角畸变，画面有噪点与时间戳条（如不需要则不写）；色彩发灰，动态范围窄
- **光线**：红外或单一顶灯，人物面部惨白
- **色调**：灰绿、灰白
- **质感**：噪点、压缩块、镜头脏污
- **运镜**：完全固定
- **声音**：无环境声或只有极低底噪、麦克风削波
- **排除**：不要电影感运镜、不要浅景深、不要打光

**短剧常用组合（一次只给一个）**

| 结尾揭示 | 以大幅慢速后拉，露出整个空间 |

| 环境交代 | 慢速升镜，露出屋顶与远处天际线 |
| 对峙压迫 | 固定低机位仰拍，人物占据画面上三分之二 |
| 时间流逝 | 完全固定，只让光变化 |

|---|---|

| 无配乐 | N/A（只在需要纯环境声时写） |

## 11 · 排错表（结果不对时，改哪一处）

| 症状 | 真因 | 改法 |
|---|---|---|
| 动作糊成一团 | 塞了多个事件 | 一个镜头只留**一个**主事件；需要多事件就加时长或切镜 |
| 镜头乱晃 / 运镜不可控 | 叠加了多种运镜 | 只给一种主运镜；取消手持/环绕 |
| 人物换脸 / 服装变 | 参考图没参与采样，或提示词里没写外观 | 上 Ref2VA + 锚点原文逐字复用；**参考图不能只当 first_frame** |
| 声音听不懂、和台词对不上 | 台词没进提示词，或没点名说话人 | 台词逐字进 `<d>`，说话人写在标签外，加"口型必须对应" |
| 多人同框时说话的人错 | 没有说话人 ID | 用 `(S1)`/`(S2)` 绑定，且只在说话的那一镜出现该 ID |
| 画面整体发黑 | 暗场没给具体光源 | 写明光源的**方位 + 颜色 + 照亮哪半边脸** |
| 出现字幕/水印/乱码文字 | H3 倾向于自己加字 | 末尾加排除句「画面内不要出现任何文字、水印、字幕条」；需要显示的文字用英文引号原样写 |
| 手指数目不对 | 手部占画面比重大 | 排除句写「右手只有五根手指」；或让手出画（"双手在画面之外"） |
| 风格前后不一 | 风格段每个镜头各写各的 | 风格段变成常量，逐字复用 |
| 台词被改写 | 分镜阶段 LLM 自行润色 | 分镜模板里锁死「dialogue 逐字照抄剧本原文」 |

## 12 · 落进本栈的两种方式

### 方式 A：作为 `presets.yaml` 的风格预设（推荐，界面可选）
把 `config_defaults/presets_h3_styles.yaml` 里的 `styles:` 合并进 `config/presets.yaml`（或 `config_defaults/presets.yaml`），点界面「重载配置」即可在项目里下拉选择。

现有链路读的是 `zh` / `render` / `en` 三个字段，其余扩展字段（`light`/`palette`/`texture`/`motion`/`audio`/`avoid`/`genres`）会被前端当作附加信息透传，不影响渲染。

### 方式 B：作为镜头提示词的前缀常量（效果最稳）
在分镜生成后，把该项目的 `style.render + style.light + style.palette + style.texture` 四段拼成一个常量串，渲染时**强制拼在每个镜头 prompt 之前**（`pipeline/worker.py::build_h3_prompt` 的 ③ 号位置）。这样即使 LLM 在分镜里自行改了风格描述，最终进模型的风格段仍完全一致。

### 12.1 本机可用的风格嵌入（ComfyUI）
`ComfyUI/models/embeddings/` 下社区贡献了 10 个 H3 风格嵌入（**非官方**，由 silveroxides 经 HF PR 提交），触发词就是不带扩展名的文件名：

`minimaxh3_art_is_explosion`（爆炸式构图）· `minimaxh3_blooming_flowers`（花朵绽放）· `minimaxh3_bullet_time`（子弹时间）· `minimaxh3_dark_magic`（黑暗魔法氛围）· `minimaxh3_fire_breath`（火焰吐息）· `minimaxh3_four_seasons`（四季变换）· `minimaxh3_kiss_camera`（接吻镜头运动）· `minimaxh3_spiral_ascent`（螺旋上升）· `minimaxh3_storm_magic`（风暴魔法）· `minimaxh3_truman_show`（楚门的世界风格）

用法：在提示词里写 `embedding:minimaxh3_dark_magic`。属于社区实验品，质量与稳定性未经本机验证，**先单镜试，别直接上全片**。
