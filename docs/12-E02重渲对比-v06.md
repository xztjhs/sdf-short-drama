## 三、镜 6（孩子特写）—— 发现并修复一个真问题

### 第一版 v0.6：回退

| | 旧版 v0.5 | v0.6 第一版 | v0.6 修正版 |
|---|---|---|---|
| 景别 | 近景/特写，孩子占满画面 | **全景**，孩子在背景里成了小点 | 中近景，孩子为主体 ✅ |
| 主体 | 孩子 | 三个成年暴徒 | 孩子 ✅ |
| 情绪 | 惊恐、攥衣角、眼泪 | 看不清 | 蹲姿、抓铁皮、惊恐眼神 ✅ |

### 根因（真实踩到的坑）

注入的场景卡有 **300+ 字**，且位置在画面描述**之前**：

```
【人物定妆】小乞丐：...
【场景（同场次保持一致）】空间：铁皮与木架搭成的路边加油站...（150+字）
                          光源：破洞屋顶漏下数道明亮阳光柱...（80+字）
                          连续性：赤鸦从门口逆光剪影进入、短刀自右靴抽出...（100+字）
墙角锈铁皮后，一个瘦小的孩子蹲着...（本镜画面，只有 60 字）
```

模型被大段"整个空间"的描述带跑，把镜头拉远去拍空间，孩子变成背景。

### 修复（两条）

1. **重排顺序**：人物定妆 → **本镜画面（带景别锁定）** → 场景一致性（瘦身版）→ 台词
2. **场景卡瘦身 + 明确约束**：
   - desc 截断到 110 字，去掉 `notes`（连续性清单不该进渲染提示词，实测会让模型去拍别的镜头内容）
   - 标题改成「场景一致性（只用于保持空间与光线相同，**不得改变下面本镜的景别与构图**）」
3. **景别锁定**：本镜描述前加 `本镜景别：近景，镜头运动：固定，画面构图以此描述为准，不要把镜头拉远`

### 修正后结果

孩子恢复为主体，中近景，蹲在锈铁皮后抓着铁皮边缘，眼神惊恐 —
景别与情绪都回来了，同时保留了场景卡的加油站空间（右侧可见加油机、地面空桶与碎玻璃）。
