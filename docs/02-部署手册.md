# 02 · 部署手册

> 从裸机到出第一条片。全程约 2 小时（其中模型下载 1 小时）。

---

## 0. 前置条件

| 项 | 要求 | 检查命令 |
|---|---|---|
| GPU | NVIDIA ≥ 12GB，本方案按 24GB 调优 | `nvidia-smi` |
| 内存 | **≥ 64GB，推荐 128GB** | `free -h` |
| 磁盘 | 模型 45GB + 输出 20GB | `df -h` |
| Docker | 24+，nvidia runtime 已注册 | `docker info \| grep -i runtime` |
| 出网 | 能访问 ModelScope | `curl -I https://modelscope.cn` |

⚠️ **内存是硬门槛**。可用内存 < 32GB 时 H3 会被 OOM Killer 静默杀掉，且容器报 ExitCode=0，极难排查。

## 2. 加 swap（强烈建议，5 分钟）

> 为什么必须：H3 在 24GB 卡上会把大量权重放 host RAM。真到了极限，有 swap 是"慢"，没 swap 是"死"。

```bash
ssh root@YOUR_SERVER_IP

# 在 NVMe 上建 64GB swap（不是 array，避免校验拖慢）
fallocate -l 64G /mnt/disks/nvme/swapfile
chmod 600 /mnt/disks/nvme/swapfile
mkswap /mnt/disks/nvme/swapfile
swapon /mnt/disks/nvme/swapfile

# 验证
free -h
```

**持久化**（Unraid 重启丢失）：

```bash
# 编辑 /boot/config/go，在最后加一行
cat >> /boot/config/go <<'EOF'

# SDF 栈 swap
if [ ! -e /mnt/disks/nvme/swapfile ]; then
  fallocate -l 64G /mnt/disks/nvme/swapfile
  chmod 600 /mnt/disks/nvme/swapfile
  mkswap /mnt/disks/nvme/swapfile
fi
swapon /mnt/disks/nvme/swapfile
EOF
```

⚠️ Unraid 的 `/boot/config/go` 已有内容，**追加不要覆盖**。

## 6. 起栈

```bash
ssh root@YOUR_SERVER_IP
cd /mnt/disks/nvme/docker/compose/sdf

# 先在 docker-compose.yml 的 api 服务里配好 LLM key
export ICOMPIFY_API_KEY=

# ⚠️ 硬底线：必须用栈名 sdf（compose 文件已写 name: sdf，-p 是双保险）
# 禁止 docker run / docker restart <容器> / Portainer 单独启停
docker compose -p sdf up -d

# 看日志
docker compose logs -f comfyui
```

**首次启动慢**（5-10 分钟）：ComfyUI 要装依赖、初始化自定义节点。

就绪标志：

```
To see the GUI go to: http://0.0.0.0:8188
```

健康检查：

```bash
curl -s http://YOUR_SERVER_IP:8188/system_stats | head -c 200
curl -s http://YOUR_SERVER_IP:8080/api/health
```

## 8. 第一条片（冒烟测试）

### 8.1 走 Web 界面

1. 打开 `http://YOUR_SERVER_IP:8080`
2. 新建项目 → 新建剧集
3. 「分镜」页粘贴一段剧本：

```
林晚在天台遇见江辞。她质问："你早就知道，对不对？"
江辞沉默，转身看向城市。
```

4. 点「生成分镜」→ 等 30-90 秒 → 自动出 2-4 个镜头
5. 切到「渲染」→ 点「开始渲染」

### 8.2 或走命令行（更快定位问题）

```bash
docker exec -it sdf-api python - <<'PY'
from pipeline import db, comfy, workflow
import json

print("ComfyUI 在线:", comfy.alive())
wf = workflow.build_h3(prompt="a woman standing on rooftop at dusk, cinematic",
                       resolution="544x960", duration=3, steps=8, seed=42)
print("工作流节点数:", len(wf))
pid = comfy.submit(wf)
print("prompt_id:", pid)
h = comfy.wait(pid, timeout=1800, on_progress=lambda e: print("→", e))
print("产物:", json.dumps(h.get("outputs"), ensure_ascii=False)[:500])
PY
```

**首次运行会慢**（编译器要 JIT 内核），第二次同参数会快 30-50%。

## 9. 24GB 显存必须知道的三个坑

详见 [06-踩坑记录](06-踩坑记录.md)。这里先列出来：

| 症状 | 原因 | 解法 |
|---|---|---|
| 一跑就 CUDA OOM | `memory_usage_factor=0.114` 让分配器不触发 offload | 升级 ComfyUI 到 0.32+；仍失败则手工改成 `1.0` |
| 1-2 秒短片 OOM，10 秒正常 | 短时长显存估算过于乐观 | 先跑长的测试 |
| 同图 OOM 过一次就永远 OOM | 坏预算被缓存 | **往画布上加任意无关节点** |

启动参数已配好，不要删：

```yaml
CLI_ARGS: --listen 0.0.0.0 --port 8188 --disable-pinned-memory
          --fp16-intermediates --reserve-vram 2.5 --disable-auto-launch
PYTORCH_CUDA_ALLOC_CONF: expandable_segments:True
```

⚠️ **不要加 `--lowvram`**——与 `--disable-pinned-memory` 冲突。
