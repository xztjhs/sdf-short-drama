# 05 · 短剧创作手册

> 给编剧/导演看的。不问技术，只管怎么把故事变成片子。

---

## 1. 一集短剧长什么样

**目标规格**

| 项 | 值 |
|---|---|
| 成片尺寸 | 1080 × 1920（9:16 竖屏） |
| 时长 | 60-120 秒（平台最佳） |
| 镜头数 | 20-40 个 |
| 单镜时长 | 3-8 秒 |
| 帧率 | 24 fps（可插帧到 48） |
| 音频 | 立体声，-16 LUFS |
| 格式 | H.264 + AAC，MP4 |

**为什么单镜不能太长**
视频模型在 5 秒后动作容易崩坏、人物开始漂移。**宁可多切镜，不要长镜头**。这也是真人短剧的语法。

---

## 2. 完整流程（5 步）

```
① 写剧本  →  ② 生成分镜  →  ③ 检查调整  →  ④ 渲染  →  ⑤ 看片改片
```

### ① 写剧本

不用写成标准剧本格式。**一段有对话的故事就行**，LLM 会拆。

**好的输入**：
```
林晚在天台等江辞。
江辞来了，她质问："你早就知道，对不对？"
江辞沉默三秒，转身看向城市灯火。
"我以为我能护住你。"他说。
林晚笑了，眼泪掉下来。
```

**不好的输入**：
```
一个女孩很伤心。（太抽象，LLM 无法拆出具体画面）
```

**原则**：
- 有具体动作（走、站、转身、抬手）
- 有具体环境（天台、雨夜、办公室）
- 有对话（对话是 H3 的强项，一次出声音）
- 有情绪转折（短剧要节奏）

### ② 生成分镜

Web 界面 → 选剧集 → 「分镜」页 → 粘贴剧本 → 点「生成分镜」。

**参数**：

| 参数 | 建议 | 说明 |
|---|---|---|
| 最多镜头数 | 30-40 | 太少不连贯，太多渲染慢 |
| 目标时长 | 90 | 秒。留空让 LLM 自己定 |

**等 30-90 秒**。LLM 会返回：

- 集标题 + 一句话剧情
- 角色表（含英文外貌锚点）
- 每个镜头：时长、景别、运镜、英文提示词、对白、音效

### ③ 检查调整（最重要的一步）

**必查四项**：

| 检查 | 怎么看 | 不合格怎么办 |
|---|---|---|
| **提示词** | 是不是英文？有没有具体画面？ | 点「改」重写 |
| **时长** | 是不是 3-8 秒？ | 点「改」调整 |
| **对白** | 该有台词的地方有没有？ | 点「改」补上 |
| **角色** | 同一角色外貌描述一致吗？ | 在项目里改角色 appearance |

**⚠️ 提示词质量决定一切。** 差提示词 = 废片，再好模型都救不了。

### ④ 渲染

「渲染」页 → 选引擎策略 → 点「开始渲染」。

| 选项 | 什么时候用 |
|---|---|
| 自动路由 | **默认，90% 情况用这个** |
| 强制 H3 | 想所有镜头都有原生音频 |
| 质量优先 | 出预告片/封面，不在乎时间 |

进度条会显示第几个镜头、预计还剩多久。

### ⑤ 看片改片

「成片」页看各镜头片段。

**常见问题与改法**：

| 问题 | 改什么 |
|---|---|
| 人物脸崩了 | 改提示词加 "detailed face, natural skin texture"；或降分辨率重出 |
| 动作不连贯 | 缩短时长；或拆成两个镜头 |
| 手部畸形 | 提示词加 "hands visible" 或让手不在画面（"hands out of frame"） |
| 画面太暗/太亮 | 提示词加 "well lit" / "bright daylight" |
| 风格不统一 | 在项目 style 里统一写死（见 §3.2） |
| 没有声音 | 该镜头可能被路由到 5B（5B 无音轨），改成强制 H3 |

## 3. 提示词怎么写

### 3.1 万能公式

```
[主体] + [动作] + [环境] + [光线] + [镜头] + [画质]
```

**示例**：
```
主体：a 26-year-old Chinese woman with long black hair, wearing a beige trench coat
动作：standing alone, wind blowing her hair, slowly turning her head
环境：on a rooftop at dusk, city skyline in background
光线：warm golden hour light, rim lighting
镜头：medium shot, slow push in, shallow depth of field
画质：cinematic, film grain, 35mm, highly detailed
```

合起来：
```
A 26-year-old Chinese woman with long black hair, wearing a beige trench coat,
standing alone on a rooftop at dusk, wind blowing her hair, slowly turning her head,
city skyline in background, warm golden hour light, rim lighting,
medium shot, slow push in, shallow depth of field,
cinematic, film grain, 35mm, highly detailed
```

### 3.2 项目级风格（保一致性）

在项目创建时设 `style`，所有镜头共用：

```
现代都市写实风格，电影感，冷暖对比光，浅景深，35mm 胶片颗粒
```

建议用英文（模型理解更准）：
```
modern urban realism, cinematic, cool-warm contrast lighting,
shallow depth of field, 35mm film grain, muted color palette
```

### 3.3 角色一致性（短剧生死线）

**问题**：同一个角色在不同镜头里长得不一样。

**解法三层**：

**第一层：外貌锚点写死**
在项目「角色」里为每个角色写一段固定的英文描述：

```
林晚 / appearance:
26-year-old Chinese woman, oval face, long straight black hair with side part,
thin eyebrows, sharp eyes, small mole under left eye, wearing a beige trench coat
```

所有镜头提示词都复用这段。`script.py` 的 SYSTEM_PROMPT 已要求 LLM 这么做，但**你自己改的时候也要遵守**。

**第二层：Ref2VA 参考图（关键镜头）**
渲染时选「质量优先」，会给有对白的镜头走 Ref2VA 模式，用角色参考图锁定长相。

需要把角色参考图放到 `input/` 目录，在角色里填路径。

**第三层：固定 seed**
同一角色的镜头用相近 seed。在「镜头列表」里可以手动设。

### 3.4 负面提示词

默认已带通用负面词：
```
blurry, distorted, watermark, low quality, extra limbs
```

**按需追加**：

| 场景 | 追加 |
|---|---|
| 不要字幕/文字 | `text, subtitles, captions, logo` |
| 不要多余人物 | `multiple people, crowd, extra person` |
| 不要奇怪手部 | `deformed hands, extra fingers` |
| 不要慢动作 | `slow motion, freeze frame` |

## 4. 镜头语言速查

### 4.1 景别

| 景别 | 英文 | 用在哪 |
|---|---|---|
| 远景 | wide shot / establishing shot | 开场交代环境 |
| 全景 | full shot | 人物全身动作 |
| 中景 | medium shot | 对话（最常用） |
| 近景 | close-up shot | 情绪表达 |
| 特写 | extreme close-up | 眼神、手部细节 |

**短剧节奏**：远景（1）→ 中景（多个）→ 近景（情绪点）→ 特写（爆点）。平均 5 秒切一次。

### 4.2 运镜

| 运镜 | 英文 | 效果 |
|---|---|---|
| 固定 | static shot / locked off | 稳定，对话用 |
| 推 | slow push in / dolly in | 强调，紧张感 |
| 拉 | pull back / dolly out | 揭示，孤独感 |
| 摇 | pan left/right | 展示环境 |
| 移 | tracking shot | 跟随人物 |
| 跟 | follow shot | 动态感 |
| 手持 | handheld camera | 真实感、慌乱 |

### 4.3 光线

| 光线 | 英文 | 情绪 |
|---|---|---|
| 顺光 | front lighting | 平和 |
| 侧光 | side lighting / rim light | 立体，戏剧性 |
| 逆光 | backlight / silhouette | 神秘，孤独 |
| 顶光 | top lighting | 压抑 |
| 底光 | underlighting | 恐怖，阴森 |
| 黄金时刻 | golden hour | 温暖，怀旧 |
| 蓝调时刻 | blue hour | 冷，忧郁 |

## 5. 产能规划

**单机（A5000）实测产能**：

| 模式 | 单集耗时 | 日产能（8h） |
|---|---|---|
| 全 H3 768p | 6-8 小时 | 1 集 |
| 混合（默认） | 2.5-3 小时 | **2-3 集** |
| 全 5B 544p | 1-1.5 小时 | 4-5 集（但无原生音频） |

**建议节奏**：
- 上午：写 3 集剧本，批量生成分镜
- 下午：批量渲染（混合模式）
- 晚上：看成片，标记要重出的镜头
- 次日早：重出失败镜头 + 成片

**批量技巧**：
- 一个项目建多集，渲染队列会按集序排队
- 夜里挂着跑，早上看结果
- 失败镜头单独重试，不用整集重跑

## 6. 质量分级（决定用哪档资源）

| 级别 | 用途 | 配置 |
|---|---|---|
| **草稿** | 试剧情、看节奏 | 全 5B，544×960，4 步 |
| **正片** | 平台发布 | 混合，544×960（H3 用 768） |
| **精品** | 预告片、封面 | 全 H3，768×1344，12-16 步，Ref2VA |

**先草稿跑通，再正片精修。** 直接上精品是浪费——剧情不对的话，画质再好也得重来。

## 7. 常见创作问题

### Q: 生成的画面和我想的完全不一样

提示词太抽象。**把抽象的换成具体的动作**。
- ❌ "她很伤心"
- ✅ "she lowers her head, tears falling, hands trembling"

### Q: 人物动起来像 PPT

时长太短或步数太低。试着：
- 时长加到 5-6 秒
- 步数加到 10-12
- 提示词加具体的连续动作（"slowly raising her hand, then turning"）

### Q: 对话口型对不上

H3 的原生音频是**先出声音再对口型**，一致性比后配好很多。如果还不对：
- 确认该镜头走的是 H3（不是 5B）
- dialogue 里只写台词，不要写"她说"这类描述
- 台词尽量短（一句话 10-15 字内）

### Q: 一集里风格跳来跳去

- 项目 style 必须设，且所有镜头继承
- 别在同一集里混用 quality_first 开关
- 后期统一调色可以救一部分

### Q: 字幕位置挡住脸

成片时字幕默认在最下方（MarginV=120）。如果人物在下半画面，改 `assemble.py` 的 `style` 参数或后期用剪辑软件加。

## 8. 交付检查清单

出片前过一遍：

- [ ] 总时长在 60-120 秒
- [ ] 没有明显的人物换脸/崩坏
- [ ] 对白能听清（音量一致）
- [ ] 字幕没挡住关键画面
- [ ] 开头 3 秒有钩子（短剧生死线）
- [ ] 结尾有悬念或反转
- [ ] 竖屏 1080×1920，无黑边变形
- [ ] 加了 AI 生成内容标识（平台合规要求）

## 9. 合规红线（必读）

⚠️ **这些不是技术问题，是法律和平台风险**：

| 项 | 要求 |
|---|---|
| **AI 标识** | 2025-09-01 起《人工智能生成合成内容标识办法》，成片须有显式+隐式标识 |
| **备案** | 平台侧对 AI 短剧有备案要求，按平台规则办 |
| **肖像权** | 不得生成真实人物（除非有授权） |
| **未成年人** | 绝对禁止任何涉及未成年人的不当内容 |
| **H3 License** | 商用需在 UI 显著显示 "MiniMax H3"；美/欧/英/韩地域受限；不得用输出训练其它模型 |
| **内容审查** | "本地无审查" ≠ "可以发违规内容"。平台封号与模型无关 |

**"无审查"的正确理解**：本地模型不会因为你写"暴力冲突""犯罪悬疑"就拒绝生成。这解决的是**题材表达受限**问题，不是**内容合规**问题。

## 10. 从小说到短剧（进阶）

如果手上有小说：

1. **先做改编大纲**：用 LLM 把小说压成 10 集大纲（每集一句话钩子）
2. **单集展开**：每集展开成 200-300 字剧本
3. **分镜**：按 §2 流程走
4. **保留原著爽点**：改编时别丢核心冲突

提示词（可直接用）：

```
你是短剧编剧。把下面这段小说改写成 90 秒短剧剧本。

要求：
1. 只保留一个核心冲突
2. 开头 3 秒必须有钩子（悬念/冲突/反转）
3. 对白简短有力，单句不超过 15 字
4. 结尾留悬念

小说原文：
<粘贴>
```
