# 08 · 快速上手（老板版）

> 不看技术细节，只看怎么用。5 分钟读完。

---

## 这是什么

一套在你 .253 服务器上跑的**短剧生产系统**：
- 你写剧本 → 它自动拆分镜 → 自动出视频 → 自动拼成片
- 全程本地 GPU 渲染，不付云端费用
- 一集 90 秒短剧，约 3 小时出片

---

## 打开

```
http://YOUR_SERVER_IP:8080
```

顶栏会显示三个状态：
- **GPU** —— 显存占用、温度。空闲时应是 `0/24GB`
- **内存** —— 可用内存。**低于 30GB 就要小心**
- **ComfyUI** —— 绿点 = 在线

---

## 做一集（4 步）

### 第 1 步：建项目

左上角「+ 新项目」→ 输入剧名。

建议在项目里设**视觉风格**（英文），全剧统一：
```
modern urban realism, cinematic, cool-warm contrast lighting, 35mm film grain
```

### 第 2 步：建剧集 + 贴剧本

「+ 新建剧集」→ 输入第几集。

在「分镜」页的文本框里贴剧本。**格式随意**，有对话有动作就行：

```
林晚在天台等江辞。
江辞来了，她质问："你早就知道，对不对？"
江辞沉默三秒，转身看向城市灯火。
"我以为我能护住你。"他说。
林晚笑了，眼泪掉下来。
```

### 第 3 步：生成分镜

点「生成分镜」，等 30-90 秒。

系统会调 icompify 的 LLM 拆成 20-40 个镜头，每个带：
- 英文提示词
- 时长（3-8 秒）
- 景别、运镜
- 对白、音效
- 自动判定用哪个引擎

**生成后必看一眼**「镜头列表」页：
- 提示词是不是具体画面（不是"她很伤心"这种抽象描述）
- 该有台词的地方有没有台词
- 同一角色的外貌描述一致吗

不对就点「改」手动修。

### 第 4 步：渲染

「渲染」页 → 保持「自动路由」→ 点「开始渲染」。

进度条会显示第几镜、还剩多少。**别关页面也别重启容器**。

一集 90 秒的片子大约 **2.5-3 小时**。

出完在「成片」页看各镜头片段。

---

## 三个必须知道的

### 1. 别在有别的东西跑的时候渲染

H3 要吃掉 20GB 显存。如果 RAGFlow 开着（它也吃 19GB），**必崩**。

渲染前先看顶栏 GPU 是不是 `0/24GB`。不是就先停掉别的。

```bash
# 停 RAGFlow（渲染完再起回来）
cd /mnt/disks/nvme/docker/ragflow
docker compose stop
```

### 2. 内存不够会"无声失败"

最坑的故障：渲染跑到一半，任务没了，日志里**没有任何报错**。

这是系统内存被 OOM Killer 杀了（不是显存问题）。

**判断**：看容器状态是不是"重启过"，日志里没有任何 CUDA 错误。

**预防**：
- 顶栏可用内存保持在 30GB 以上
- 加内存在路上（128GB）

### 3. 引擎不是随便选的

系统按这个规则自动分配：

| 镜头类型 | 用谁 | 为什么 |
|---|---|---|
| 有对白 | **H3** | 一次出画面+人声+音效，最强能力 |
| 有音效要求 | **H3** | 同上 |
| 空镜/远景 | Wan2.2 | 快 4 倍，反正后期配音乐 |
| 动作/打斗 | Wan2.2 | 快，且 H3 多人容易崩 |

想强制全用 H3 → 渲染页选「强制 H3」（但会慢 4 倍）

## 什么能做，什么别做

### ✅ 适合做

- 都市情感、悬疑、职场、甜宠 —— 有对话有场景的
- 60-120 秒竖屏
- 一集 20-40 个镜头
- 日更 2-3 集（混合模式）

### ⚠️ 要小心

| 内容 | 风险 |
|---|---|
| **真实人物** | 肖像权，必须有授权 |
| **未成年人** | 绝对禁止任何不当内容 |
| **露骨内容** | 国内平台封号级风险，与模型无关 |
| **出海发行** | H3 License 排除美/欧/英/韩 |

### ❌ 做不到

- **2K 输出** —— 开源权重只到 768 短边（2K 是 MiniMax 托管服务功能）
- **长镜头** —— 视频模型 5 秒后动作会崩，必须切镜
- **完美的角色一致性** —— 需要 Ref2VA + 参考图，且不是 100%

## 产能实话

| 模式 | 单集耗时 | 日产能 |
|---|---|---|
| 全 H3 768p | 6-8 小时 | 1 集 |
| 混合（默认） | 2.5-3 小时 | 2-3 集 |
| 全 5B 544p | 1-1.5 小时 | 4-5 集（无原生音频） |

**这是单张 A5000 的真实上限。** 要更多产能，得加卡。

---

## 出问题怎么办

| 现象 | 先看 |
|---|---|
| 网页打不开 | 容器还活着吗：`docker ps --filter name=video-` |
| 渲染不动 | ComfyUI 日志：`docker compose logs -f comfyui` |
| 显存不够 | 顶栏 GPU，或 `nvidia-smi`——有别的进程在占 |
| 渲染失败 | 「镜头列表」页看失败原因，单镜重试 |
| 分镜生成失败 | icompify API key 配了吗 |
| 出来的片没声音 | 那镜可能被路由到 5B（5B 无音轨），改成强制 H3 |

详细排查见 `04-运维管理手册.md`。
