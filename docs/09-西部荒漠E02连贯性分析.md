# 西部荒漠 E02 连贯性问题分析（2026-10-22）

分析对象：`西部荒漠 / E02 谁才是猎人`，38 个镜头，160 秒，全部 H3（720×1280，8 步）。

---

## 一、先说结论

**不是单一原因，是 6 个问题叠加。** 按影响排序：

| # | 问题 | 影响 | 性质 |
|---|---|---|---|
| 1 | 角色没有任何参考图，也没有外貌锚点注入 | 人物脸/发型/服装每镜随机 | **流程缺陷**（最致命） |
| 2 | 每镜独立生成语音，无跨镜声音身份 | 同一角色 3 个声音（"语音脑裂"） | **模型能力边界** |
| 3 | 台词没有标注说话人，提示词也没有口型提示 | H3 猜错人说话 / 发出乱语 | **提示词缺陷** |
| 4 | 镜头衔接（尾帧→首帧）不分场景，跨场景也接 | 外景尾帧接内景首帧 → 画面溶解变形 | **流程缺陷** |
| 5 | 场景/光线每镜自由描述，同一空间写成不同样子 | 加油站内景每镜像不同地点 | **提示词缺陷** |
| 6 | "两名暴徒"当成一个整体描述，有时只出现一个 | 人数忽多忽少 | **提示词缺陷** |

其中 **1、3、4、5、6 全是可修的**，第 2 条要换方案（见第四节）。

---

## 二、证据（来自 E02 实际数据）

### 2.1 角色参考图：0 张

```
赤鸦               locked=1  ref_image=空
掠夺者头目         locked=1  ref_image=空
掠夺者暴徒（两名） locked=1  ref_image=空
小乞丐             locked=1  ref_image=空
```

四个角色全是纯文字描述。H3 每次从零开始"想象"这张脸。

### 2.2 角色描述漂移（同一角色，不同镜写法不同）

| 镜 | 赤鸦的写法 |
|---|---|
| 1 | 一个红发女人背着行囊…黑色皮衣 |
| 2 | 赤鸦的背影，蓬松鲜红卷发…黑色皮衣肩线磨损 |
| 3 | 一双高筒战术靴（**没写是谁**） |
| 9 | 一个红发女人的剪影…红发照成燃烧般的亮红色 |
| 10 | 赤鸦的脸，苍白皮肤…冷红色嘴唇 |
| 12 | 赤鸦站在门框里…皮衣袖口磨损起毛 |
| 15 | 赤鸦的眼睛，瞳孔微微收缩 |
| 30 | 赤鸦站着…冷红色嘴唇张开 |

看出来了吗：**"28 岁、苍白脸、齐肩红发、黑色皮衣、右眉疤"这种固定锚点，从来没被逐字复用**。
每镜的 LLM 都用自己的话重新描写一遍，细节自然漂移。

角色库里其实存了完整锚点：

```
赤鸦: English anchor: a 28-year-old woman, striking pale face with...
```

但**它从来没进过渲染提示词**。`worker.build_h3_prompt()` 只拼 `shot.prompt` + 台词 + 音效，
而 `shot.prompt` 是分镜 LLM 自己重写的自由文本。

### 2.3 台词无说话人（14 个台词镜，只有 2 个写了说话动作）

```
镜 5  dl=水芯片在哪？      提示词含说话动作=True   chars=[头目, 暴徒×2]
镜 6  dl=别过来……          提示词含说话动作=False  chars=[小乞丐]
镜 7  dl=闭嘴，小鬼。      提示词含说话动作=False  chars=[头目, 小乞丐]
镜10  dl=放开那孩子。      提示词含说话动作=False  chars=[赤鸦]
镜11  dl=一个人也敢来？    提示词含说话动作=False  chars=[头目, 小乞丐, 暴徒×2]  ← 3 人同框
镜25  dl=上！              提示词含说话动作=False  chars=[头目, 暴徒×2]
镜31  dl=芯片你拿走，命留下！ 提示词含说话动作=False  chars=[头目, 赤鸦]
```

以镜 11 为例：三个人同框，台词是头目的，但提示词写的是
"光头壮汉松开手转身面向门口…镜头随他的转身摇" —— **没有任何"他在说话"或"嘴在动"的信号**。
H3 只能自己猜，猜错就是"另一个人动嘴"，或者干脆生成一段无人声的乱音。

### 2.4 镜头衔接不分场景

`chain_frames: true` 会把上一镜的**最后一帧**作为下一镜的**首帧**。

E02 的实际场景切换：

| 镜 | 场景 |
|---|---|
| 1-3 | 荒漠公路（外景） |
| 4 | 加油站正面（外景） |
| 5-8 | 加油站内部 |
| 9-15 | 门口对峙（内外交界） |
| 16-24 | 内部打斗 |
| 25-33 | 内部决战 |
| 34-38 | 内部 → 走出门外 → 公路 |

镜 3（靴子踩柏油路）的尾帧被塞给镜 4（加油站正面）；
镜 4（外景强逆光）的尾帧被塞给镜 5（内景阳光柱）。
**模型被迫在两个完全不同的空间之间做形变过渡** —— 这就是"场景脑裂"最直接的来源。

而且衔接会把上一镜的任何瑕疵（糊脸、多手指、错位构图）原样喂给下一镜，逐镜放大。

### 2.5 场景描述不统一

同一个加油站内部，各镜光线写法：

```
镜 5: 破洞屋顶漏下几道明亮的阳光柱
镜 6: 明亮光柱从铁皮缝隙打在他脸上
镜11: 明亮阳光柱扫过他的肩膀
镜26: 灰尘在光柱里慢慢飘，镜头缓慢环绕，强剪影对比
镜27: 背景虚化，动作带轻微拖影
```

没有一处说明"这是同一个空间、同一个时刻、光源位置固定"。模型每镜重建一次布景。

### 2.6 人数不确定

`掠夺者暴徒（两名）` 是一个角色条目，描述是"两个穿废铁甲的暴徒"。
但：

```
镜 8: 一个暴徒抬脚踹翻铁皮水桶…另一个暴徒把铁管扛在肩上   ← 两个
镜16: 一个暴徒举着铁管从侧面冲过来                        ← 只一个
镜20: 第二个暴徒举起粗糙步枪                              ← 只一个
镜25: 两个暴徒退到他身后                                  ← 两个
```

观众看到的是"有时候两个人，有时候一个人"。这属于分镜实体建模问题。

## 三、附带发现（加剧问题的两个流程点）

### 3.1 E02 是 v0.4 之前生成的英文分镜翻中文前的老数据？

不是。E02 是中文分镜（38/38 中文），但**「锁定基础信息」里的角色锚点仍是英文**：

```
赤鸦: "English anchor: a 28-year-old woman, striking pale face with..."
```

中文分镜时 `_locked_info_text()` 会把英文锚点原样塞进提示词，
LLM 看到英文锚点、写中文描述 → 语言转换过程中细节又损失一层。

### 3.2 分镜没有 scene_id 字段

输出结构里只有 `seq / duration / shot_size / camera / prompt / dialogue / sfx / characters`。
没有"这场戏在哪个场景""镜头属于第几场"。所以：

- 衔接逻辑无法判断"这是不是同一场景"
- 场景卡无法复用
- 观众感知的"场"和系统感知的"镜"完全脱钩

## 四、解决方案（供选择）

### 方案 A：提示词层加固（低成本，当天可上线）

| 措施 | 做法 | 解决 |
|---|---|---|
| A1 锚点强制注入 | 渲染时把角色库里**逐字**的外貌锚点拼进每个镜头提示词，不让 LLM 复述 | 2.2 |
| A2 说话人显式化 | 分镜新增 `speaker` 字段；提示词强制写"XX 的嘴唇开合，说出这句话" | 2.3 |
| A3 场景卡 | 分镜新增 `scene_id` + `scene_desc`；同场景镜头共用同一段场景描述原文 | 2.5 |
| A4 衔接分场景 | `chain_frames` 只在 `scene_id` 相同时接帧；跨场景改文生或场景定场帧 | 2.4 |
| A5 实体拆分 | "两名暴徒"拆成 暴徒甲/暴徒乙 两个角色 | 2.6 |
| A6 连续性审查 | 分镜生成后追加一次 LLM pass，检查锚点/场景/光线漂移并修正 | 全部 |

- 成本：改分镜提示词 + worker 拼装 + 一次审查调用（每集多 1 次 LLM，约 30 秒）
- 预期：人物脸仍有 20-30% 漂移（纯文字无法锁脸），但服装/发型/场景/人数/说话人会明显稳定
- 语音问题**不解决**

### 方案 B：角色参考图 + Ref2VA（一致性最强，需要准备素材）

- 每个角色出 1 张定妆照（可用 H3 文生图先出，再人工挑）
- 用 `h3-ref2va-int8`（模型已在盘上，20.97GB，配置里现在已启用）走 r2v 模式
- 需要新写一个 ref2va 工作流（当前 `workflow.py` 只有 fl2va 的 `MiniMaxH3ImageToVideo`）
- 预期：人物脸一致性大幅提升（这是 H3 官方推荐做法）
- 成本：每角色 1 张图 + 工作流开发 + 单镜耗时可能略增
- 语音问题**仍不解决**

### 方案 C：语音统一（针对"语音脑裂"）

| C1 合并台词镜头 | 同一场景的连续对白合并成一个 H3 长镜（6-8 秒），减少换声次数 | 立即可做，损失切镜节奏 |
| C2 后期统一配音 | H3 只出画面+环境声，台词走 TTS（同一音色克隆），后期对齐 | 声音完全统一，但失去 H3 的原生口型同步 |
| C3 音色参考 | Ref2VA 支持 3 段音频参考，可锁定音色 | 需要每个角色一段干净音频样本 |

### 方案 D：结构性调整

- **D1 减少镜头数**：38 镜 → 20-24 镜，单镜 6-8 秒。接缝少一半，连贯性天然提升。
- **D2 分场渲染**：一场戏内所有镜头一次性提交（同一 seed 前缀 + 场景首帧锚定），替代逐镜独立。

## 五、我的建议（组合拳）

**立刻做：A1 + A2 + A3 + A4 + A6（方案 A 全套）** —— 一天内可上线，零额外素材，
能解决 5/6 个问题。

**配合：D1 减少镜头数** —— 分镜规则里把"每集 30-40 镜"改成"20-24 镜，单镜 6-8 秒"。

**下一步（需要你准备）：B 方案** —— 你给四个角色各挑一张定妆照（或我先生成候选图你选），
我接 Ref2VA 工作流，人物脸才能真锁住。

**语音**：先用 C1（合并台词镜头）压一压；如果仍不可接受，再上 C2（TTS 统一配音），
代价是放弃 H3 原生口型同步。

## 六、验收方式

改完后用同一剧本重跑 E02 前 6 镜（约 1.5 小时），对比检查：

1. 赤鸦在 6 个镜头里发型/服装/脸型是否一致
2. 有台词的镜头，动嘴的是不是正确的人
3. 跨场景处（外景→内景）是否还有溶解变形
4. 两人/三人在场的镜头，人数是否稳定
5. 同一角色的声音是否接近（C1 生效后应明显改善）
